# ADR 0009: 実行した外部コマンドをリングバッファに記録しUIに表示する

## Status

Accepted (2026-07-13)

## Context

gitreant が裏で何を実行したのか（特に `git fetch`）をユーザーが確認できる手段がなかった。vscode-git-graph の出力チャネルのように、実行コマンドのログを見たい。

## Decision

- サーバの `AppState` に**容量200のリングバッファ**を持ち、外部コマンドを実行するたびに1エントリ（完了時刻・対象リポジトリid・コマンドライン・成否・失敗時のstderr）を記録する。現時点で外部コマンドは `git fetch`（ADR 0007）のみ。gix によるリポジトリ読み取りはコマンド実行ではないため記録しない。
- `GET /api/log` がバッファ全体を古い順で返す。フロントエンドはトップバーのトグルで下部ペインを開き、新しい順に表示する。ペインが開いている間はリポジトリ状態の更新に合わせて再取得する。
- ログはメモリ上のみ（サーバ停止で消える）。永続化はしない。

## Consequences

- fetch の失敗理由（認証エラー等）がUIから直接確認できる。
- 将来外部コマンドが増えた場合も同じバッファに記録すればよい。コマンドラインの組み立てと実行を分離しておく（`git::fetch_command` / `git::fetch_remotes`）ことが前提になる。
- 容量を超えた古いエントリは黙って消える。長期の監査ログ用途ではない。
