# ADR 0056: 週の始まりの曜日を選べるようにする

## Status

Accepted (2026-10-29)

## Context

履歴を週で区切る表示は 2 つある。行の下のカレンダー（[ADR 0050](0050-calendar.jp.md)）は「各列を月曜に始まる 1 週間」とし、行数の推移のグラフ（[ADR 0047](0047-net-candles.jp.md)）は期間について「週は月曜に始まる」としている。月曜始まりは ISO の週だが、世界の多くの地域や、読み手が見慣れた多くのカレンダーは日曜に週を始める。並びの違うカレンダーは、読むときに目が引っかかる。

## Decision

- **設定で月曜か日曜かを選ぶ。** 設定に専用のグループを設けてセグメンテッドボタンを置き、既定は月曜とする。コマンドパレットは、日時形式と同じく、選択肢ごとに項目を出す。選んだものはブラウザに保存する。
- **2 つの表示がどちらも従う。** カレンダーの列は選んだ曜日から始まる。グラフの週ごとのロウソクと棒も、時間足で週を選んだときも、自動で週になったときも、同じ曜日から始まる。2 つの表示で週の区切りがずれることはない。
- **カレンダーは同じ曜日に名前を出す。** 行の名前は、どの行に来ても月曜、水曜、金曜に出す。

## Consequences

- 期間の始まりとカレンダーの週は、週の最初の曜日を引数に取る。どちらも純粋関数にし、どちらの曜日についても単体テストで確かめる。
