# ADR 0051: グラフの範囲を狭め、四半期や年で区切れるようにする

## Status

Accepted (2026-10-26)

## Context

行数の推移のグラフ（[ADR 0043](0043-cumulative-chart.jp.md)）は、読み込んだうちで最も古いコミットから足し上げる。行の表示やカレンダー（[ADR 0050](0050-calendar.jp.md)）がページを読み進めるほど読み込みはさかのぼるので、グラフは広がる一方になる。数年ぶんを読み込むと、最近の数週間は右端の細い帯に縮み、そこだけを見る手段がない。また、[ADR 0049](0049-chart-timeframe.jp.md) の時間足は月までなので、数年ぶんでは読みきれないほどのロウソクが並ぶ。

## Decision

- **時間足の横に範囲を置く。** 全部、5 年、1 年、6 か月、3 か月、1 か月のボタンを並べる。全部以外を選ぶと、最も新しいコミットからその長さだけさかのぼったコミットを、ローカルのカレンダーに従って描く。全部は読み込んだすべてのコミットを描く。最初は全部とし、時間足と同じく選んだものは保存しない。
- **足し上げは範囲の頭から始める。** 範囲の中では、加えた行と削った行を範囲の最初のコミットから 0 で足し上げるので、その範囲でどれだけ変わったかが読める。ロウソク、棒、ポインタを乗せたときの表示、カーソルの位置のコミットの一覧は、どれもこの和を読む。
- **四半期と年。** 時間足に四半期と年を足す。ローカルのカレンダーに従い、四半期は 1 月、4 月、7 月、10 月に始まる。自動は、月で 60 本ほどを超えるときは四半期を、それも超えるときは年を選ぶ。

## Consequences

- 範囲は和と最も新しいコミットの時刻の純粋関数にし、四半期と年とあわせて単体テストで確かめる。
- 範囲を狭めている間は、最も新しいコミットが変わらない限り、読み込みが進んでもグラフは変わらない。
