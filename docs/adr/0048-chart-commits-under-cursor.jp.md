# ADR 0048: 行数の推移のグラフで、カーソルの位置のコミットを一覧する

## Status

Accepted (2026-10-25)

## Context

[ADR 0043](0043-cumulative-chart.jp.md) のグラフと、そのロウソク足と棒（[ADR 0047](0047-net-candles.jp.md)）は、時間とともにどれだけ変わったかを見せる。ただ、どのコミットがその変化を作ったかは見せない。それを探すには、グラフを離れて、日付を頼りに行の表示を探すことになる。

グラフは各コミットをその時刻の位置に置く。長い期間を描くと、数時間のうちのコミットは同じピクセルに重なり、線の 1 つの段になる。カーソルはその段に止まるが、名前を出すのはそのうち最も近い 1 件だけである。

## Decision

- **クリックでカーソルの位置のコミットを並べる。** グラフをクリックすると、カーソルから 3 ピクセル以内に描かれたコミット、つまりカーソルが止まった段のコミットを、グラフの右のパネルに並べる。並べるのはグラフがそこで足し上げているコミット、つまり HEAD の最初の親で、新しい順とする。各コミットには、件名、行数、短い ID を出す。一覧はロウソクの期間に従わない。1 本のロウソクには離れた位置に描かれたコミットも入るので、それを並べると、クリックした場所と一覧が合わなくなる。別の場所をクリックすると、一覧を入れ替える。
- **並んだコミットから行へ。** 並んだコミットを右クリックすると、行と同じコミットのメニューを開き、先頭に「行に移る」を置く。選ぶとグラフを閉じ、行の表示でそのコミットを選び、画面に入るようにスクロールする。メニューから親や子へ移るときと同じ動きにする。
- **一覧を閉じる。** パネルの見出しの × と Esc で閉じる。コミットのメニューを開いているときは、Esc はまずメニューを閉じる。

## Consequences

- 一覧はクリックしたときのカーソルの位置の時刻を持つので、パネルがグラフを狭め、グラフが残った幅に合わせて描き直しても変わらない。どのコミットがカーソルの位置に入るかはレイアウトの純粋関数にし、単体テストで確かめる。
- 長い履歴では 1 日ぶん以上のコミットが並ぶこともあり、短い履歴では 1、2 件が並ぶ。
