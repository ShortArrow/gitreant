# ADR 0044: 行の表示のグラフに、各コミットが変えた行数の厚みをつける

## Status

Accepted (2026-10-23)。[ADR 0042](0042-terrain-mode.jp.md) を置き換える。

## Context

[ADR 0042](0042-terrain-mode.jp.md) では、各コミットが加えた行と削った行（[ADR 0041](0041-diff-stats-per-commit.jp.md)）を、グラフを傾けた別のモードの柱として見せた。行から向きを変えた表示は、横の行と並ぶグラフとしては読めなくなり、見るためには行の表示と入れ替える必要があった。

イラストを描く道具のブレンドは、平らな絵に奥行きを持たせる。図形のコピーを、ある位置から別の位置へ少しずつずらして重ねると、立体に見える。この描き方なら、各コミットの大きさを、行の横にすでにあるグラフに載せられる。

## Decision

- **行の表示のグラフに載せる。** メイングラフの、行数を数え終えたコミットのノードと辺の後ろに厚みを描く。行、ノード、辺の位置は変えない。ADR 0042 の地形モードは取り除く。
- **追加は上へ、削除は下へ。** コミットのノードのコピーを、加えた行の数だけ左上へ、削った行の数だけ右下へ、2 ピクセルごとに重ねる。厚みは `3 × log2(1 + 行数)` ピクセルで、36 を上限とする。1 行の修正も lockfile の書き換えも読めて、厚みが行から離れすぎないようにする。
- **コミットの間はフカヒレにする。** 辺のコピーで、子の厚みと親の厚みをつなぎ、厚みが履歴に沿ったフカヒレになるようにする。フカヒレのコピーはノードと同じ幅にし、両端の柱と同じところまで届かせる。点線のリンクと未コミットの行のリンクは平らなままにする。まだ数えていないコミットには厚みをつけない。
- **緑と赤の半透明。** 追加の側を緑、削除の側を赤にし、それぞれを 1 つの半透明の形として描く。コピーが重なっても濃くならず、1 つにまとまる。厚みはポインタを受けない。手前のノードはこれまでどおりクリックやホバーができ、ノードにポインタを乗せたときは、最初の親の列から外れたものと一緒に薄くなる。
- **はみ出す分の余白。** 厚みが横に届く最大の幅だけ、メイングラフを左右とも内側に寄せ、厚みが切れないようにする。
- **設定。** グラフの設定で厚みを入り切りできる。既定は入で、選んだものは保存する。コマンドパレットからも切り替えられる。

## Consequences

- コピーは数の純粋関数にして単体テストで確かめ、グラフと同じ SVG に描く。3D のライブラリは足さない。
- ペインは、数え終えたコミットと辺ごとに、厚み 2 ピクセルにつき 1 枚のコピーを描く。
- 厚みの伸びる向きと深さを変えて傾ける操作は、同じコピーの上に作れる。[ROADMAP](../ROADMAP.jp.md) に置く。
