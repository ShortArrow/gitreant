# ADR 0035: グラフのノードから移動・比較・チェックアウトする

## Status

Accepted (2026-10-21)

## Context

グラフのノードはコミットメニューを開き、ホバーでハッシュを出す（[ROADMAP](../ROADMAP.jp.md) の 0.2.0）。それ以外の、履歴の中でのコミットの位置は目でグラフを追って読むしかない。ノードがどのコミットから続いているか、次にどのコミットが来るか、親子でない 2 つのコミットの間で何が変わったかである。ペインが持つ選択中のコミットは 1 つで、行かノードのクリックで選ぶ。キーボードからは選べない。

ブランチのバッジにホバーすると、その先端から辿れない行はすでに薄くなる（`graph.ts` の `reachableFrom`）。差分のエンドポイントはコミットと最初の親しか比べない。`POST /api/checkout` は `git switch <ref>` を実行し、コミット ID だけを渡すと git が拒否する。

書き込みはコミットメニューから git コマンドで行い（[ADR 0014](0014-branch-operations.jp.md)、[ADR 0021](0021-tag-operations.jp.md)）、QUALITY.jp.md はチェックアウトをすでにその一つに数えている。

## Decision

以下はペインのメインのグラフに適用する。サブモジュールのグラフは選択を持たず、どれも適用しない。

- **系譜。** ノードにホバーすると、読み込み済みのコミットのうち、その first-parent の連なりにない行・ノード・線を薄くする。ノードから離れるか再読み込みで終わる。ブランチのバッジのホバーも、行だけでなくノードと線を同じように薄くする。
- **キーボードでの選択。** フォーカス中のペインで、入力欄・メニュー・ダイアログ・パレットのどれもキーボードを使っていないとき:
  - `↑` / `↓` で選択を上・下の行に移す。何も選んでいなければ、4 つの移動のどれでも先頭の行を選ぶ。
  - `←` / `→` で、左・右のいちばん近いレーンにある、最も近い行のコミットに移す。同じ距離なら上の行を選ぶ。その向きにレーンがなければ選択は動かない。親と子へはメニューから移る。一直線の区間では親と子は上下の行になり、キーを割り当てても `↑` / `↓` と同じになるためである。
  - `Enter` で「Diff all」と同じく全ファイルの差分を開く。
  - `Esc` で選択を解除する。

  差分ペインがグラフに代わって出ている間は矢印キーを受けず、`Esc` は差分の行の選択を外し、選択がなければペインを閉じる。選んだ行は見える位置までスクロールする。既定でオフの設定で、4 つの移動に `k` / `j` / `h` / `l` を足せる。矢印キーはそのまま使える。
- **メニューの親と子。** コミットメニューに、読み込み済みの親と子を「親」「子」として、短い ID と要約で並べる。選ぶとそのコミットを選択する。ないものは項目を出さない。親と子として扱うのは読み込み済みのコミットだけである。
- **2 つのコミットの比較。** コミットを選んだまま別のコミットのメニューを開くと「選択中と比較」が出る。読み込み済みのコミットの中で一方がもう一方の祖先ならそれを、そうでなければ選択中のほうを基点にする。差分ペインは基点 → 対象を `base..target` という見出しで表示し、パーマリンクは古い側に基点、新しい側に対象を使う。詳細ペインには、基点を上に、対象を下にして 2 つのコミットを並べ、変わったファイルを行数とともに一覧にする。ファイルを選ぶと差分がそこまでスクロールする。どちらかのペインを閉じるか選択を変えると比較は終わる。未コミットの行は加わらない。サーバはコミット差分と同じ読み取りで 2 つのコミットのツリーを比べるので、`diff` 属性とバイナリの判定（[ADR 0033](0033-diff-attribute.jp.md)）が効く。
- **detached でのチェックアウト。** コミットメニューに「チェックアウト（detached）」を出し、ブランチのチェックアウトと同じくその場の Yes / Cancel で確かめる。サーバは `git switch --detach <commit>` を実行し、ほかの操作と同じく記録してクライアントに通知する。受け取るのは完全なコミット ID だけで、リクエストがその代わりに git のオプションを渡すことはできない。手元の変更のために git が拒否したときは、操作のエラーとして表示する。

## Consequences

- 読み込んだページより先の親や子には、履歴をさらに読み込むまでメニューから届かない。
- 系統の違う 2 つのコミットは選択中のほうを基点に比べる。基点と対象を入れ替えるには、もう一方を先に選ぶ。
- キーがグラフに届くのはペインのほかの要素が使っていないときだけなので、後から足すショートカットはこの 6 つ（と任意の 4 つ）とぶつからないか確かめる必要がある。
