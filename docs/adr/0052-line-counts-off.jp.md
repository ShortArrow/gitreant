# ADR 0052: 行の行数を出さないこともできるようにする

## Status

Accepted (2026-10-27)

## Context

各行は、そのコミットが加えた行と削った行を `+N −M` で出し、設定によっては行の先頭に棒で描く（[ADR 0046](0046-line-count-bars.jp.md)）。同じ数は、グラフの厚み（[ADR 0044](0044-graph-thickness.jp.md)）、行数の推移のグラフ、カレンダー（[ADR 0050](0050-calendar.jp.md)）にも出る。大きさをそちらで読むなら、行の幅は件名やほかの詳細に回したいことがある。設定は棒か数字かを選ぶチェックボックス 1 つで、どちらも出さないことはできなかった。

## Decision

- **3 択の設定を 1 つにする。** 棒のチェックボックスに代えて、設定に専用のグループを設け、数字、棒、なしのセグメンテッドボタンを置く。既定は数字とする。コマンドパレットは、日時形式と同じく、選択肢ごとに項目を出す。
- **なしでは行に何も出さない。** なしを選ぶと、行には数字も棒も出さず、棒の幅も空けない。厚み、グラフ、カレンダー、コミットの詳細が数を読むので、数の読み込みは続ける。
- **前の選択を引き継ぐ。** 選んだものは専用のキーに保存する。まだ保存がなく、チェックボックスで棒を選んで保存してあれば棒とし、それ以外は数字とする。

## Consequences

- 保存した選択の読み取りは 2 つの保存値の純粋関数にし、単体テストで確かめる。
