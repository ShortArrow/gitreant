# ADR 0059: 厚みの輪郭を設定にし、既定では出さない

## Status

Accepted (2026-10-29)

## Context

[ADR 0058](0058-thickness-depth-order.jp.md) は、レーンごとの厚みを 1 つの半透明の形として描き、輪郭を付けた。「同じ色の半透明の形 2 つは、どちらの順に重ねても同じに見える」からである。輪郭は、ブランチが交わる所でどのレーンが手前かを示す。しかし交わりの少ない履歴、とくにコミットが 1 列に並ぶだけの履歴では、どの形にも何も示さない線が付き、絵を混み合わせるだけになる。

## Decision

- **グラフの設定で輪郭を出す。** グラフの設定の、厚みのチェックボックスの隣にチェックボックスを置き、輪郭を出せるようにする。既定は出さない。コマンドパレットからも切り替えられる。選んだものはブラウザに保存する。
- **設定で変わるのは輪郭だけとする。** 側とレーンの描く順は、輪郭を出すかどうかにかかわらず ADR 0058 のとおりとする。

## Consequences

- E2E テストで、最初はレーンに輪郭がなく、設定を入れると輪郭が付くことを確かめる。
