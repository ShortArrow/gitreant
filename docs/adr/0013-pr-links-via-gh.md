# ADR 0013: PR 情報は gh CLI に委譲し、TTL キャッシュ付きの遅延取得にする

## Status

Accepted (2026-07-13)

## Context

ブランチに対応する open な Pull Request があるとき、バッジから PR の
Web ページへ飛べるようにしたい。PR とブランチの対応は GitHub 側の状態
であり、リポジトリのローカル状態からは分からない。

## Decision

- 取得は `gh pr list --state open --json number,url,headRefName` に委譲する
  （ADR 0007/0011 と同じ CLI 委譲パターン）。ユーザーの `gh` 認証に
  そのまま乗り、gh 未インストール・未認証・GitHub リモート無しの場合は
  静かに空リストへ縮退する。
- ネットワーク呼び出しなのでリポジトリ読み取り（`/api/repos`）には
  含めず、専用の `POST /api/prs` をフロントエンドが RepoCard 表示時に
  遅延取得する。結果はリポジトリ毎に **TTL 5分**でキャッシュする。
- 実行した gh コマンドはコマンドログ（ADR 0009）に記録する。
- UI はブランチバッジの末尾に `#<番号>` のリンクセグメントを足し、
  新しいタブで PR ページを開く。

## Consequences

- gh が使える環境ではブランチから PR へワンクリックで飛べる。
- PR の開閉はキャッシュ TTL（最長5分）遅れて反映される。即時反映が
  必要になったら fetch ボタンでのキャッシュ破棄を検討する。
- GitHub 以外のホスティング（GitLab 等）は対象外。必要になれば
  別 ADR で拡張する。
