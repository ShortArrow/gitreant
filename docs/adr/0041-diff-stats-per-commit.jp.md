# ADR 0041: 各コミットが加えた行数と削った行数を表示する

## Status

Accepted (2026-10-23)

## Context

行には、コミットの要約、作者、時刻、ハッシュが出るが、どれだけ変えたかは出ない。1 行だけ変えたコミットも、1,000 行を書き換えたコミットも、diff を開くまで同じに見える。この数は、変更の大きさで履歴を見せる表示（加えた行と削った行を高さにして、グラフを傾けて見せるものなど）の土台にもなる。

数えるには、すべてのコミットを親と比べる必要がある。コミットごとに木を比べることになるので、署名の確認と同じく（[ADR 0037](0037-deferred-signature-check.jp.md)）、リポジトリの最初の表示をこれで待たせるには重すぎる。

## Decision

- **何を数えるか。** コミットが加えた行と削った行は、最初の親からそのコミットへの `git diff --numstat` の数で、名前の変更は検出する（`-M`、git の既定）。マージは最初の親と比べるので、マージで取り込んだものが出る。根のコミットは空の木と比べる。すべてのファイルを数え、バイナリのファイルは `--numstat` の出すとおり 0 行とする。
- **表示の後に、バックグラウンドで数える。** ビューを読むときは、数えるのを待たない。すでに分かっている数を、各コミットの `stat` として載せる。残りはサーバが表示の順に 256 件ずつ数え、1 つのリポジトリにつき同時に 1 本だけ走らせる。数えるときは、コミットとその最初の親を 1 行ずつ `git diff-tree --stdin -r --numstat -M --root` に渡す。1 回分を数え終えるたびに数を保持し、コマンドをコマンドログに記録し（[ADR 0009](0009-command-log.jp.md)）、リポジトリを名指す `counted` イベントを送る。クライアントは、`verified` のときと同じく、そのリポジトリのビューを読み直す。
- **コミット ID ごとに保持する。** コミットの数は変わらないので、セッションは動いている間ずっと保持し、消さない。
- **行に表示する。** 行の署名バッジの前に `+N −M` を、加えた行と削った行の色で出す。まだ数えていないコミットには何も出さない。未コミットの行は、これまでどおりファイル数を出す。

## Consequences

- グラフは、これまでどおり履歴をたどり終えた時点で表示される。数は、署名の確認と並んで、上から 1 回分ずつ埋まる。
- コマンドログには、1 回分ごとに 1 件が加わる。
- 変更の大きさの上に作る表示（傾けたグラフや累積のグラフなど）は、ビューの `stat` を読める。どちらも [ROADMAP](../ROADMAP.jp.md) に置く。
