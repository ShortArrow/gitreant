# ADR 0054: ドロワーの絞り込みで入れ子の行も探せるようにする

## Status

Accepted (2026-10-29)

## Context

ドロワーは、リポジトリのサブモジュールとほかの worktree を、そのリポジトリの行の下にアコーディオンで入れ子にする。絞り込みは最上段の行だけを名前かパスで探していたので、入れ子の worktree やサブモジュールは絞り込みで見つけられなかった。[ADR 0028](0028-worktrees.jp.md) は、これを「既知の制約」として残していた。worktree はブランチ名で探すことが多いが、行に出ているブランチ名も探す対象ではなかった。

## Decision

- **入れ子の行も、最上段の行と同じく当てる。** サブモジュールは名前かパスで、worktree は名前、パス、ブランチ名で当てる。大文字と小文字を区別しない部分一致は、最上段の行と同じとする。
- **親は残し、当たった行まで開く。** 最上段の行の名前とパスが当たらなくても、入れ子の行のどれかが当たれば、その行は一覧に残す。絞り込みのあいだは、そのアコーディオンを開いて、当たった入れ子の行だけを出す。
- **親自身が当たれば、今までどおりにする。** 最上段の行そのものが当たったときは、アコーディオンを利用者が残した開閉のままにし、入れ子の行をすべて出す。

## Consequences

- どの行を出し、それぞれの下にどの入れ子の行を出すかは、行と絞り込みの文字列の純粋関数にし、単体テストで確かめる。
