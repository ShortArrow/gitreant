# ADR 0046: 行の行数を横棒で描く

## Status

Accepted (2026-10-24)

## Context

各行は、そのコミットが加えた行と削った行を `+N −M` として出す（[ADR 0041](0041-diff-stats-per-commit.jp.md)）。数字は正確だが、1 行ずつ読むことになる。行を縦に追いながら、どのコミットが大きいか、加えるほうと削るほうのどちらに偏っているかを一目で見るのは難しい。取引画面の板のように両側を棒で描けば、目で追いながら両方が見える。

## Decision

- **設定で、数字の代わりに棒にする。** 設定で、各行の数を `+N −M` の代わりに棒で描く。既定では切っておき、選ぶまでは数字のままにする。選んだ設定は保存し、コマンドパレットからも切り替えられる。
- **1 本の軸から両側へ。** 真ん中に細い縦の軸を置き、削った行を赤で左へ、加えた行を緑で右へ伸ばす。どの行も軸の位置をそろえるので、縦に追うと各コミットがどちらに偏っているかが分かる。
- **行の先頭に、行と同じ高さで置く。** 棒は行の高さいっぱいに描き、行が重なって 1 本の棒の列になるようにする。置く場所は、バッジや件名より前の、行の先頭とする。行の先頭はどの行でも同じ位置から始まる。数字は右寄せの詳細の中にあり、その幅は行ごとに違う。まだ数えていない行は棒の幅だけ空けておき、件名の位置もそろえる。
- **厚みと同じ尺度。** 棒の長さは、同じ数に対する [ADR 0044](0044-graph-thickness.jp.md) の厚みと同じ `3 × log2(1 + 行数)` ピクセルで、36 を上限とする。1 行の修正もロックファイルの書き換えも読めて、コミットの棒と厚みがそろう。
- **数はホバーで。** 正確な数は、今の数字と同じく棒のツールチップに出す。まだ数えていないコミットには棒を出さない。

## Consequences

- 棒は数によらず、どの行でも同じ決まった幅を取る。
- 棒の長さは厚みと同じ純粋関数から出すので、2 つがずれることはない。
