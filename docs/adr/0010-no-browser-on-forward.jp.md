# ADR 0010: 稼働中サーバへの転送時はブラウザを開かない

## Status

Accepted (2026-07-13)

## Context

`gitreant` を2回目以降に実行すると、リポジトリは稼働中サーバへ転送される（単一インスタンス動作、ADR 0002）が、そのたびに `open_browser` が新しいタブを開いていた。既にタブを開いて使っているユーザーにはタブが増えるだけで邪魔になる。既存タブへのフォーカス移動も検討したが、ブラウザはセキュリティ上、外部プロセスやほかのタブからの `window.focus()` を許可しないため実現できない。

## Decision

- **転送パス（`forward_to_running`）ではブラウザを開かない**。代わりに稼働中サーバのURL（`already serving on http://127.0.0.1:<port>`）を標準出力に表示し、必要ならユーザーがクリック/コピーできるようにする。
- 新規起動パス（detach起動・`--foreground`）の自動オープンは従来どおり（`--no-open` で抑止可能）。

## Consequences

- タブを閉じてしまった状態で2回目の起動をした場合、ブラウザは自動では開かない。表示されたURLを開くか、いったん `--shutdown` してから起動し直す。
- SSE によるライブ更新（既存タブに転送結果が即反映される）が前提。
