# ADR 0022: ペイン分割は「リポジトリ比較」用途に絞り、2ペイン横並びから始める

## Status

Accepted (2026-07-17)

## Context

複数リポジトリを同時に見比べたい（mo 的な複数リポジトリ監視の強化）。
汎用のペインツリー（VS Code 風の任意分割）や、同一リポジトリ内の
グラフ／diff 分離も候補にあったが、主用途は「別リポジトリを並べる」
ことだと確認した。

## Decision

- **2ペイン固定（左右）から始める。** 状態モデルはペイン配列
  `Pane { tabs, activeId }[]` ＋フォーカス中ペインの添字で持ち、
  将来の N 分割へはモデル変更なしで拡張できる形にする。
- **1リポジトリ＝全ペインでタブ1枚。** 「右のペインで開く」は移動で
  あり複製ではない。同一リポジトリの複数ビューは持たない（選択状態や
  タブ名の一意性が保たれ、比較用途に複製は不要）。
- **分割の操作は3経路**: タブの右クリックメニュー、ドロワー項目の
  右クリックメニュー、コマンドパレット（コマンドレジストリ登録）。
- **ペインはタブが尽きたら消える。** 右ペインの最後のタブを閉じる
  （またはリポジトリ削除で消える）と単一ペインに戻る。左ペインが
  尽きたら右が左に詰まる（配列から空ペインを除くだけ）。
- **フォーカス**: ペイン内のクリックでフォーカスが移る。ドロワーの
  通常クリックはフォーカス中ペインに開く。リポジトリ操作コマンド
  （ブランチ checkout 等）はフォーカス中ペインのカードだけが
  レジストリに登録する。
- ペイン遷移ロジックは純関数（`paneModel.ts`）に切り出し、
  ユニットテストで固定する。

## Consequences

- タブバーはトップバーからペイン内（各ペインの先頭）へ移る。
- ペイン幅は当面 1:1 の等分。ドラッグでの比率調整は必要になったら
  `ResizeHandle` を流用して追加する。
- グラフ／diff の分離表示や上下分割はこの ADR の対象外。必要に
  なればペイン配列をツリーへ拡張する別 ADR を起こす。
