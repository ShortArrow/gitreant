# ADR 0042: 加えた行と削った行で起伏をつけて、履歴を地形として見せる

## Status

[ADR 0044](0044-graph-thickness.jp.md) に置き換えられた（2026-10-23）。

## Context

[ADR 0041](0041-diff-stats-per-commit.jp.md) で、各コミットが加えた行数と削った行数を `+N −M` として行に出した。行を 1 つずつ読んでも、大きな変更が履歴のどこに集まっているかや、どのブランチがそれを運んだかは見えない。高さなら見える。グラフを奥へ傾け、各コミットを変更の大きさだけ持ち上げれば、履歴全体の大きな変更が山として一度に見える。

傾けたグラフは横の行とそろわなくなるので、行と同じ配置には置けない。

## Decision

- **ペインごとの、別のモードにする。** ペインのヘッダーのボタンで、行の表示と地形を切り替える。地形はグラフと行の場所に出る。diff のペインは、これまでどおり両方の代わりに出る。ペインは行の表示で開き、選んだモードは保存しない。
- **何を描くか。** ペインが行の表示で読み込んだメイングラフのコミットと、その辺を地面に描く。地形はペインいっぱいに出てスクロールしないので、続きは読み込まない。サブモジュールの領域と squash マージのリンクは描かない。
- **柱。** 各コミットは、加えた行の数だけ緑の柱を上に、削った行の数だけ赤の柱を下に伸ばす。高さは `8 × log2(1 + 行数)` ピクセルとし、1 行の修正も lockfile の書き換えも読めるようにする。まだ数えていないコミットと、未コミットの行には柱を立てない。
- **投影。** コミットは、行の表示のグラフと同じ位置で地面に立つ。ペインの決まった位置に描く地面の点を支点とし、地面を支点を通る垂直の軸のまわりに回転の角度だけ回す。次に傾きの角度だけ奥へ倒し、そのまま画面に写して（正射影で、遠近はつけない）、倍率をかける。支点のまわりに回すので、支点は回しても描いた位置に残る。柱は奥から手前の順に描く。傾きは 0°（真上から）から 85° の間にとどめる。
- **最初の表示。** 地形は回転 30°、傾き 60° で開く。支点は読み込んだコミットの中ほどに置いてペインの中央に描き、すべてのノードと柱がペインに収まるまで縮小する。ただし、本来の大きさより拡大はしない。収める計算は開いたときに一度だけ行い、後から数が届いても動かさない。
- **動かし方。** 横にドラッグすると回り、縦にドラッグすると傾く。回す中心は、ドラッグを始めたところにあるコミットのノードか柱、なければポインタの下の地面とする。その点を、描かれている位置のまま支点にするので、その点はポインタの下に残り、ほかがそのまわりを回る。キーで回すときも同じ支点を使う。右ドラッグか Shift ドラッグで、地面をポインタと一緒に動かす。ホイールでは、ポインタの下の地面をその場に残したまま、0.02 倍から 8 倍の間で拡大・縮小する。地形にフォーカスがあるときは、`←` / `→` で 15° ずつ回し、`↑` / `↓` で 5° ずつ傾け、`+` / `-` でペインの中央を中心に 1.25 倍ずつ拡大・縮小し、`0` で最初の表示に戻す。行がないので、このモードの間は [ADR 0035](0035-graph-node-navigation.jp.md) の選択のキーを止める。どの変化もアニメーションなしでその場で反映するので、`prefers-reduced-motion` のために別の扱いは要らない。
- **読み方。** コミットのノードか柱にポインタを乗せると、ハッシュ、要約、`+N −M` を出す。

## Consequences

- 投影は純粋関数にして単体テストで確かめ、行の表示のグラフと同じく SVG に描く。3D のライブラリは足さない。
- 読み込んだコミットはすべて描くので、数千件を読み込んだペインは数千本の柱を描く。
- [ROADMAP](../ROADMAP.jp.md) に残る累積のグラフは、同じ数を別の形で見せるものとして、このモードと並べられる。
