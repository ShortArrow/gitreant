# ADR 0060: リポジトリの追加を一覧の末尾の行から行う

## Status

Accepted (2026-10-29)

## Context

[ADR 0055](0055-drawer-add-panel.jp.md) は、リポジトリの追加をボタンの奥に移し、「ドロワーの見出しの追加ボタンで、追加の欄を開く」とした。見出しは絞り込みと並び替えの上にあり、ボタンが行を足す先の一覧から離れている。そこにある小さなアイコンは、何を足すのかもあまり伝えない。タブを縦に並べるブラウザ、たとえば Chromium や Firefox は、一覧の最後を「新しいタブ」の行で終える。行を足す操作が、その行が現れる場所に置かれている。

## Decision

- **一覧の末尾の行でリポジトリを追加する。** 最後のリポジトリの後に、プラスの付いた「リポジトリを追加」の行を置いて一覧を終える。ほかのボタンと同じくボタンの表示の設定に従う。ドロワーの見出しの追加ボタンはなくす。
- **行はその場で開く。** 押すと、その行が、ADR 0055 の欄にあったパスの入力欄と「フォルダを選ぶ…」に変わる。振る舞いは変えない。Enter で入力したパスを追加し、追加に成功したときや Escape で行に戻り、失敗したときはエラーとともに開いたままにする。
- **空のドロワーでは開いておく。** 一覧が空と分かったら、行を入力欄として出す。そのときドロワーでできるのは追加だけだからである。

## Consequences

- リポジトリを追加する E2E の補助関数は、欄を開いていたのと同じく、行が閉じていれば開いてから入力する。
