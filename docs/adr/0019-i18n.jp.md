# ADR 0019: i18n は型付き自前辞書で行い、言語は設定から切り替える

## Status

Accepted (2026-07-15)

## Context

UI 文言が英語・日本語の混在だったため、言語を選べるようにして一貫させたい。対象文言は現状 70 個弱で、複数形・数値書式などの高度な要求はない。

## Decision

- ライブラリ（react-i18next 等）は入れず、**TypeScript の型付き辞書**（`i18n.ts` の en / ja、`MsgKey` はコンパイル時検査）と `useT()`（SettingsContext 経由）で実装する。プレースホルダは `{name}` の単純置換のみ。
- 言語設定は **Auto（`navigator.language` が ja 系なら日本語、それ以外は英語）/ English / 日本語** の3値で、設定ダイアログから変更、localStorage に保存（ADR 0015 のパターン）。
- **GitHub と共有するドメイン用語は翻訳しない**: バッジ（Signed / Verified / Unverified / HEAD）、署名種別ラベル（"Signed (OpenPGP)" 等）、コマンドログの中身（実行コマンド文字列・ユーザー操作の記録）。ログは実行内容の記録であり表示文言ではない。
- 両辞書のキー一致は Vitest で検証する。

## Consequences

- 対応言語の追加は辞書1個の追加＋設定の選択肢1行で済む。
- 複数形処理は英語の "1 file / N files" を2キーで表す素朴な方式。言語が増えて立ち行かなくなったら、その時に ICU MessageFormat 系の導入を別 ADR で判断する。
