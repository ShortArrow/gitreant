# ADR 0012: ユーザー操作はクライアント側で記録しコマンドログとマージ表示する

## Status

Accepted (2026-07-13)

## Context

ログペイン（ADR 0009）はサーバが実行した外部コマンドの記録であり、
ユーザーが UI で何をトリガーしたか（fetch・reload・リポジトリ追加/削除）
は写らない。ユーザーへの操作フィードバックとして表示したい。

## Decision

- ユーザー操作はフロントエンドの状態としてクライアント側でのみ記録する
  （`logModel.ts` の `UserAction`）。サーバのコマンドログは「実行された
  外部コマンドの記録」という意味を保ち、混ぜない。
- ログペインは両者を時刻でマージして表示する（`mergeLog`）。同時刻なら
  操作をコマンドより古い側に置く — 操作がコマンドの引き金だから。
- 操作ログはページリロードで消える。フィードバック用途なので永続化しない。

## Consequences

- サーバ API は変更なし。操作の記録漏れ（SSE 起因の自動 reload など）は
  仕様 — ユーザーが起こした操作だけを写す。
- 将来サーバ側で記録すべき操作が出たら、その時はエントリ種別を持つ
  サーバログへの統合を別 ADR で検討する。
