# ADR 0057: カレンダーの塗り方のボタンをボタンの表示の設定に従わせる

## Status

Accepted (2026-10-29)

## Context

ボタンの表示の設定（[ADR 0015](0015-client-settings.jp.md)）は、操作のボタンをアイコン、アイコンとラベル、ラベルのいずれかで描き、「共通の `LabeledButton` を通」るボタンに効く。少数から 1 つを選ぶものはセグメンテッドボタンで、それぞれはテキストのラベルを持つラジオ入力なので、常に文字で出ていた。カレンダーの上で、両方、加えた行、削った行のどれで塗るかを選ぶボタンは、ヘッダーのアイコンのボタンと並んでいるのに、そこで唯一設定に従わない。

## Decision

- **セグメンテッドボタンの選択肢はアイコンを持てる。** 各選択肢は、ラベルとともにアイコンを指定できる。すべての選択肢がアイコンを持つときは、`LabeledButton` と同じくボタンの表示に従い、アイコン、アイコンとラベル、ラベルのいずれかで描く。ラベルはツールチップと支援技術のために残す。
- **カレンダーの塗り方には差分のアイコンを使う。** 両方、加えた行、削った行には、差分、加えた行、削った行のアイコンを出す。
- **値を書いた選択肢は文字のままにする。** 設定のグループと、グラフの時間足と範囲にはアイコンを付けない。言語名や「1Y」のように、ラベルそのものが値だからである。

## Consequences

- E2E テストで、カレンダーの塗り方をボタンの表示ごとに確かめる。
