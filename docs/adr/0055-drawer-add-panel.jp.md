# ADR 0055: リポジトリの追加をドロワーの見出しのボタンから行う

## Status

Accepted (2026-10-29)

## Context

ドロワーの上端には、パスの入力欄、参照ボタン、追加ボタンが 1 行に並び、常に出ていた。この並びは、参照で欄を埋めて追加で送る形に読めるが、参照は選んだフォルダをすぐに追加し、欄には触れなかった。そのすぐ下には絞り込みの欄があり、見た目が同じで役割の違う入力欄が 2 つ並んでいた。幅 260 ピクセルのドロワーでは、2 つのボタンのぶんパスの欄が狭くなっていた。リポジトリの追加はたまにしか行わず、ドロワーは主に絞り込みと選択に使う。

## Decision

- **ドロワーの見出しの追加ボタンで、追加の欄を開く。** 折りたたみボタンの隣に置き、ほかのボタンと同じくボタンの表示の設定に従う。
- **欄には、パスの入力欄と「フォルダを選ぶ…」を置く。** 入力欄で Enter を押すと入力したパスを追加し、「フォルダを選ぶ…」はフォルダ選択を開いて選んだフォルダを追加する。別の追加ボタンは置かない。
- **用が済んだら欄を閉じる。** 開くと入力欄にフォーカスを移す。追加に成功したとき、Escape を押したとき、見出しのボタンをもう一度押したときに閉じる。追加に失敗したときは、エラーとともに開いたままにする。
- **空のドロワーでは欄を開いておく。** リポジトリが 1 つもないときは、そこでできるのは追加だけだからである。

## Consequences

- E2E テストは 1 つの補助関数でリポジトリを追加し、欄が閉じていれば開いてから入力する。
