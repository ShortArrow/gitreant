# ADR 0045: グラフの背景をドラッグして、厚みを傾ける

## Status

Accepted (2026-10-23)

## Context

[ADR 0044](0044-graph-thickness.jp.md) では、数え終えたコミットに厚みをつけ、加えた行の分を左上へ、削った行の分を右下へ伸ばした。向きが決まっていると、高い柱やフカヒレの後ろにあるものが隠れる。深さが決まっていると、設定を切る以外に、グラフを平らに見直す方法がない。

## Decision

- **背景をドラッグして傾ける。** グラフの背景を横にドラッグすると、厚みが伸びる向きが 1 ピクセルにつき 0.5° 回る。上へドラッグすると厚みが深くなり、下へドラッグすると浅くなって、真上から見たように厚みがなくなるところまで下がる。ノードと点線のリンクは、これまでどおりのクリックとドラッグを受ける。
- **動かせる範囲。** 深さは 0 から 1 までとし、1 は ADR 0044 の厚みとする。向きは一周回せる。傾くのはドラッグしている間だけで、離すと最初の左上、深さ 1 に戻る。グラフはいつも同じ向きで読める。傾きは保存しない。
- **行は動かさない。** 行、ノード、辺の位置は変えない。メイングラフの左右に取る余白は、厚みがどの向きにでも届く最大の幅とし、回しても列がずれたり厚みが切れたりしないようにする。

## Consequences

- 傾きはドラッグの純粋関数にして、単体テストで確かめる。
- 厚みを出している間、グラフは左右に、向きが決まっていたときの 22 ピクセルではなく 36 ピクセルの余白を取る。
