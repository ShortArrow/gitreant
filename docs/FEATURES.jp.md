# 機能ガイド

[English](FEATURES.md) | [日本語](FEATURES.jp.md)

gitreant でできることを分野別にまとめる。起動方法とコマンドラインのオプションは [README](README.jp.md) を参照。設計の判断は [adr/](adr/) にある。

## リポジトリを並べる

- **複数のリポジトリを 1 画面で扱う。** 左のドロワーにリポジトリを一覧表示し、追加・削除・名前やパスでの絞り込み・並び替えができる。追加はパスの入力か、ネイティブのフォルダ選択ダイアログで行う。
- **起動中のサーバに追加される。** 別のディレクトリで `gitreant` を実行すると、既に動いているサーバにそのリポジトリが加わり、同じ画面に並ぶ。
- **タブと 2 つのペイン。** 開いたリポジトリはタブになる。タブやドロワーの右クリックから右側のペインで開けるので、2 つのリポジトリを横に並べて比べられる。タブは中クリックで閉じられる。
- **ドロワーの状態表示。** 各リポジトリに、未コミットの変更数・push していないコミット数・追跡先のないブランチ数を小さく表示する。
- **サブモジュールと worktree の入れ子。** サブモジュールを持つリポジトリは、その下にサブモジュールを入れ子で並べる。`git worktree` の linked worktree も元のリポジトリの下に入れ子で並び、チェックアウト中のブランチ名を添える。どちらもクリックで独立したビューとして開ける。
- **ライブ更新と読み込みの進み具合。** リポジトリの追加・削除は Server-Sent Events で他のブラウザにも反映する。リロードボタンでディスクから読み直す。大きなリポジトリは、読み込み中のコミット数をドロワーとペインに表示し、グラフの行は読み込んだ分から順に表示する。

## コミットグラフ

- **レーンと色はサーバで計算する。** チェックアウト中のブランチを左端の直線に置き、分岐は右へ、マージは右から合流する。ブランチの線は端から端まで同じ色で描き、stash には専用の色を付ける。色は、使用中の列が持っていない最小の色を選ぶので、隣り合う列は違う色になる。
- **HEAD とマージ。** HEAD のコミットは中抜きの輪で描く。マージコミットのメッセージは薄く表示する。
- **ノードの操作。** ノードにホバーするとハッシュを表示し、その first-parent の連なりにない行・ノード・線を薄くする。クリックでそのコミットを選ぶ。右クリックでコミット行と同じメニューを開き、フル ID のコピー、タグやブランチの作成、親や子への移動ができる。origin が github.com か gitlab.com にあれば、コミットの Web ページの URL をコピーしたり、そのページを開いたりもできる。ハッシュのクリックでフル ID をコピーする。
- **バッジ。** ブランチ・タグ・stash を別々のバッジで描く。リモートのブランチやリモートに push 済みのタグには、リモート名の区切りを付ける。ブランチのバッジにホバーすると、読み込み済みのコミットのうち、その先端からたどれない行・ノード・線を薄くする。
- **stash。** stash は、輪の中にドットを置いた 1 つのノードにたたんで描く。設定で、index と未追跡ファイルの内部コミットを点線で開いて見せられる。
- **サブモジュールのグラフ。** サブモジュールを持つリポジトリでは、サブモジュールのグラフを左側に並べ、サブモジュールのポインタを動かしたコミットどうしを点線で結ぶ。設定で切り替えられる。サブモジュールごとにグラフを名前だけの細い帯にたため、行の文字に幅を譲れる。たたんだ状態はリポジトリごとに保存する。サブモジュールのノードにホバーするとそのコミットを表示し、右クリックで ID か、サブモジュール自身の origin にあるコミットの Web ページをコピーできる。ノード以外の場所や帯を右クリックすると、サブモジュールをタブで開ける。開く先は、今のペインか右のペインを選べる。
- **作者のアイコン。** GitHub の作者アイコンを各行に表示する。設定で消せる。
- **加えた行と削った行。** 各行に、コミットが最初の親に対して加えた行数と削った行数を `+N −M` で出す。数はグラフを表示した後に埋まる。設定で、数字の代わりに各行の先頭に棒で描ける。軸の左へ削った行、右へ加えた行を、厚みと同じ対数の尺度で伸ばし、数はツールチップに残す。
- **厚み。** グラフの、行数を数え終えたコミットに半透明の厚みをつける。加えた行の数だけ緑で左上へ、削った行の数だけ赤で右下へ、対数の大きさで伸びる。コミットの間の辺は、その厚みをフカヒレとしてつなぐ。グラフの背景を横にドラッグすると伸びる向きが回り、縦にドラッグすると深さが変わって、0 まで浅くできる。離すと元に戻る。フカヒレはコミットの柱より薄い。グラフの設定で切れる。
- **行数の推移。** ペインのヘッダーのボタンで、行の代わりに、HEAD の最初の親をたどって加えた行（上向き）と削った行（下向き）を、コミットの時刻に沿って足し上げたグラフを出し、その差を 2 本の間に描く。読み込んだうちで最も古いコミットから始まる。凡例で各線の名前を示し、ポインタを乗せると、最も近いコミットとその時点の和を出す。同じ軸に、差のロウソク足と、期間ごとに加えた行と削った行の棒も描く。1 本の期間は、範囲に合わせて日、週、月から選ぶ。凡例の名前を押すと、その系列を出し入れできる。グラフをクリックすると、カーソルの位置に重なるコミットを横に並べる。右クリックすると「行に移る」を選べる。

## コミットの詳細と差分

- **詳細ペイン。** コミットをクリックすると、メッセージ全文・作者・日時・署名の状態・親コミット・変更ファイルの一覧を表示する。作者名は GitHub のプロフィールへのリンクで、メールアドレスや親コミットの ID はクリックでコピーできる。
- **変更ファイル。** ファイルはフラット表示とディレクトリのツリー表示を切り替えられ、増減した行数を添える。右クリックで相対パスと絶対パスをコピーしたり、OS の既定のアプリで開いたりできる。
- **差分ペイン。** ファイルをクリックすると差分を開く。インラインと左右分割を切り替えられ、行内で変わった箇所を強調する。「Diff all」は全ファイルの差分をまとめて開き、もう一度押すと閉じる。
- **2 つのコミットの比較。** コミットを選んだまま別のコミットを右クリックすると、2 つを比べられる。差分ペインは、古い（祖先の）コミットから新しいコミットへ変わったファイルをすべて、`base..target` という見出しで表示する。詳細ペインには 2 つのコミットと、変わったファイルを行数とともに並べる。詳細は [ADR 0035](adr/0035-graph-node-navigation.jp.md)。
- **改行コードの変更。** 改行コード（LF と CRLF）だけが変わったファイルには「改行コードのみ」のラベルを付ける。差分では変わった行末に印を出し、見出しに変換の向き（`LF → CRLF` など）を示す。詳細は [ADR 0029](adr/0029-line-ending-changes.jp.md)。
- **行の選択。** 差分の行番号をクリックして行を選び（Shift+クリックで範囲）、その行のコピーや GitHub のパーマリンクのコピーができる。
- **ペインの幅。** ドロワーと詳細ペインの幅はドラッグで変えられ、次回も保たれる。

## 作業中の状態

- **未コミットの変更。** 作業ツリーに変更があると、HEAD の上に破線の行として表示する。開くと変更ファイルの一覧と、HEAD との差分を見られる。詳細は [ADR 0027](adr/0027-uncommitted-changes-row.jp.md)。
- **別の worktree でチェックアウト中のブランチ。** バッジに印を付け、git が拒否するチェックアウトはメニューで無効にする。詳細は [ADR 0028](adr/0028-worktrees.jp.md)。

## リポジトリへの操作

リポジトリを書き換えるのは、ここに挙げる明示的な操作だけで、どれも git コマンドに委ねる。書き換えない範囲は [QUALITY.jp.md](QUALITY.jp.md) にまとめてある。

- **fetch。** ボタンで、表示中の全リポジトリに `git fetch` を実行する。失敗したリポジトリはエラーとして表示する。
- **ブランチ。** バッジの右クリックで、名前のコピー・チェックアウト・現在のブランチへのマージができる（確認付き）。コミットの右クリックで、そのコミットにブランチを作ったり、そのコミットを detached HEAD でチェックアウトしたりできる（確認付き）。
- **タグ。** コミットの右クリックでタグを作り、タグバッジの右クリックで削除する。
- **実行したコマンドの記録。** 下部のログペインに、実行した git コマンドと画面上の操作を時刻付きで残す。

## GitHub と署名

- **プルリクエスト。** `gh` CLI がインストール・認証済みなら、ブランチバッジに open なプルリクエストへのリンクを付ける。squash マージ済みで残っているブランチからは、プルリクエストが取り込まれたコミットへ点線を引く（設定で切り替え可）。
- **署名。** 署名付きコミットにバッジを付ける。ローカルの gpg で検証できれば Verified か Unverified、できなければ Signed と表示する。グラフは検証が終わる前に表示し、それまではバッジの代わりに脈動する仮置きを出す。gpg に鍵を足した後は、設定ダイアログか `gitreant refresh` で検証し直せる。

`gh` と `gpg` は任意で、無ければ該当する表示が消えるだけになる。何が使えるかは `gitreant doctor` で確かめられる。

## キーボードと設定

- **コマンドパレット。** Ctrl+K（macOS では Cmd+K）で開き、リポジトリの切り替え・fetch・リロード・テーマや表示の切り替え・ブランチのチェックアウトなどをキーボードで実行する。
- **選択の移動。** フォーカス中のペインで、`↑` / `↓` で上・下の行、`←` / `→` で隣のレーンのいちばん近いコミット、`Home` / `End` で先頭・末尾の行を選ぶ。`Enter` で全ファイルの差分を開き、`Esc` で選択を解除するか差分を閉じる。設定で `k` / `j` / `h` / `l` と `gg` / `G` を足せる。
- **設定ダイアログ。** UI の言語（自動・英語・日本語）、日時の表示形式（ISO・ロケール・相対）、操作ボタンの見た目（アイコン・アイコンとラベル・ラベル）、グラフの表示（squash の点線・stash の内部・作者アイコン・サブモジュールのグラフ）と、`hjkl` での選択の移動を切り替える。
- **テーマ。** ダークとライトを切り替えられる。
- **環境情報。** Info ダイアログに、CLI と画面の版・サーバ・ブラウザなどの情報を集め、まとめてコピーできる。

## 起動と配布

- **単一のバイナリ。** 画面を埋め込んだ 1 つの実行ファイルで、実行時に別の依存は要らない。
- **ターミナルから切り離して起動。** 既定でバックグラウンドで動き、`gitreant --shutdown` で止める。`--foreground` で前面に残す。`gitreant list` で動いているサーバを一覧でき、`--shutdown`・`restart`・`refresh` は `--port` がなくても、動いている唯一のサーバを見つける。`--verbose` を付けると、各リポジトリがどう加わったか（起動時・CLI・ブラウザ）も表示する。
- **専用ウィンドウ。** `--app` で、アドレスバーのない専用ウィンドウとして開く（Chromium 系のブラウザが必要）。
